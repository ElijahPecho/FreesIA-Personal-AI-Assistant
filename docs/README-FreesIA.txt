Project FreesIA

Instructions to Run:

1. Make sure you have Python 3.8 or higher installed.
2. Install required packages (it will check and install if you run the program anyways)
3. Run the main script by opening FreesIA shortcut

Notes:
- If you get missing package errors, install them using pip install <package-name> or python -m <package-name>.
- Make sure your Python environment is activated.
